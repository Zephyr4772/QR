# QR

A small command-line QR code generator in Python.

## Usage

```bash
git clone https://github.com/Zephyr4772/QR.git
cd QR
pip install qrcode[pil]
python main.py
```

The script prompts for the text or URL to encode and writes a PNG.

## Why

A single-purpose utility, kept because it's genuinely useful for one-off QR codes
without visiting a website that logs what you encode.
